Flutter Zero 模板项目脚手架工具（CLI）。

📚 完整文档（命令参考、目录结构、配置）请访问：**[Flutter Zero 文档站](https://dboy233.github.io/flutter_zero_doc/)** 的 CLI 参考章节。

## 快速开始

```bash
dart pub global activate fluzer

# 从模板创建新项目
fluzer create my_app

# 在项目中生成功能模块骨架并自动注册 DI
fluzer new user
```
